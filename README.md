# Bharath Kumar K — Portfolio (Glass Dev Showcase)

React + Vite portfolio with Framer Motion animations and Lenis smooth scrolling.

## Run locally
```
npm install
npm run dev
```

## Build / deploy
```
npm run build      # outputs to dist/
```
- **Netlify**: build command `npm run build`, publish directory `dist`
- **Vercel**: import the repo (Vite is auto-detected)

## Edit content
- All copy, projects, skills and links: `src/data.js`
- Layout and sections: `src/App.jsx`
- Colors, fonts, spacing: `:root` at the top of `src/index.css`
- Replace the photo: `src/assets/bharath.jpg`

Remember to set your real email in `LINKS.email` inside `src/data.js`.
